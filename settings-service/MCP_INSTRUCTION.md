SettingsService MCP — manages YAML configuration templates and the secrets they reference. BEFORE invoking any tool of this MCP, load the `how_to_use_settings` prompt: it explains the data model (templates, secrets, the Shared scope, levels, remote-datacenter variants), the placeholder syntax, the privacy rules of each tool, and the recommended discover-then-read-then-write workflow. Skip that prompt and you will misinterpret tool output (especially the missing-secret markers and the local/remote rendering rules).
