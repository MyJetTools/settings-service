SettingsService MCP — manages YAML configuration templates and the secrets they reference, grouped by `product_id`. BEFORE invoking any tool of this MCP, load the `how_to_use_settings` prompt: it explains the data model (products, templates, secrets, the Shared scope, levels, remote-datacenter variants), the placeholder syntax, the privacy rules (secret VALUES are never exposed by this MCP), and the recommended discover-then-read-then-write workflow. Two prompts are exposed: `how_to_use_settings` (no arguments — load it first) and `product_prompt` (argument `product_id` — loads a specific product's description and free-form context). Skip `how_to_use_settings` and you will misinterpret tool output (especially the missing-secret markers and the local/remote rendering rules).
